# NEXACARE — Hospital Management System

NEXACARE is a static hospital management dashboard prototype built with HTML, CSS, and vanilla JavaScript.

## Startup instructions

From the project folder, run either of the following commands:

```bash
cd "c:\Users\BMSIT\Documents\hospital"
py -m http.server 8000
```

If `py` is not available on your system, use:

```bash
cd "c:\Users\BMSIT\Documents\hospital"
python -m http.server 8000
```

Then open this URL in your browser:

```text
http://localhost:8000
```

## Project structure

- `index.html` — layout and dashboard content
- `styles.css` — dashboard styling and responsive design
- `script.js` — sidebar navigation switching between dashboard and placeholder pages

## Notes

- This is a frontend foundation only.
- No database, authentication, or external API integrations are included.
- Dashboard values are demo-only labels for design and planning.
